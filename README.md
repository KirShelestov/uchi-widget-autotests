Тестовое задание для AQA стажёра в компании учи

Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```

Что исправлено
--------------

- `has correct title` падал с `Cannot read properties of undefined (reading 'click')`: статьи в виджете
  подгружаются асинхронно, а `locator.all()` не ждёт элементов и возвращал пустой массив.
  Теперь `getPopularArticles()` сначала ждёт первую статью.
- Селектор кнопки "Написать нам" `[class^=btn]` находил 7 элементов (обёртки и кнопки оценки статьи),
  из-за этого клик падал на strict mode. Заменён на `[data-test=button_feedback_form]`.
- Проверка заголовка через `expect(await ...textContent()).toEqual(...)` читала текст сразу после клика,
  до смены экрана. Заменена на `toHaveText`, который ждёт нужный текст.
- Обёртка виджета искалась через `.sc-dino-typography-h` - это служебный класс Stencil, который появляется
  только после гидратации. Заменено на поиск по самому виджету с кнопкой открытия.
- На главной идёт A/B тест редизайна (кука `ab_mainpage_redesign`). В варианте `b` виджета помощи нет вообще,
  поэтому примерно каждый пятый прогон падал по таймауту. В `beforeEach` выставляется `ab_mainpage_redesign=a`.
- Виджет появляется примерно через 9-10 секунд после загрузки страницы, таймаут теста увеличен до 60 секунд.
